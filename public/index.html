    1. Event

    This name is what the spectator screen shows.

    Timing and points rules
    Gate timing

    Gate calls quicker than this are ignored, so a double tap or a double detection cannot make a lap.

    After Start, the horn sounds at a random moment in this range so nobody can jump it. Freestyle and casual practice start at once.

    Points

    First place scores the first number, and so on. Places past the end score 0. Race and endurance sessions score points.

    2. Pilots

    Registration order is the seed order for snake draws and A/B/C finals.

      3. Channels

      Two channels closer than 15 MHz cannot share a heat. A pilot keeps the same channel when it still fits.

        4. Round

        Add a Lua format

        Format scripts use FPVTrackside’s generate() and standings() API. Put .lua files in the scripts folder, or add one here.

        Stages and points summaries

        Rounds join the stage marked “next”. A points summary totals a stage, can drop each pilot’s worst round, and can carry places from the stage before.

          OBS scenes and recording

          The desk can switch OBS scenes and record each heat. Settings stay in this browser.

          Where these rules come from

          Points, channels, start holds, and session rules follow FPVTrackside 2.78, read from the .NET libraries inside its installer. Camera timing has its own page: ArUco markers on the gate time each pilot's laps from their video, and still video can mark a crash. Without it, a person calls the gate here.
